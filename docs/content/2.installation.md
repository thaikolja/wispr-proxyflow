# Installation

## From source

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"          # dev deps: pytest, mitmproxy, pyinstaller
```

## First run

```bash
python3 wispr_pro.py start       # proxy + relaunch Wispr Flow → Pro
```

On first start the tool creates a local CA and state under `~/.wispr_pro/`:

| File | Purpose |
|------|---------|
| `config.toml` | Rewrite values (edit to persist changes) |
| `proxy.pid` | PID of the running proxy |
| `mitmproxy/` | CA certificate + mitmproxy data |

If the app cannot connect (or to enable HTTPS interception on other
devices), trust the CA once:

```bash
python3 wispr_pro.py trust       # asks for your password
```

## Prebuilt binary or app

- Grab the `.dmg` from the latest GitHub Release (contains `Wispr Pro.app`).
- Or build it yourself — see [Build & package](/4.build).
- Double-click `Wispr Pro.app` to start the proxy in the background
  (logs: `~/.wispr_pro/proxy.log`).

```bash
# CLI from inside the bundle:
"dist/Wispr Pro.app/Contents/MacOS/wispr-pro" start --no-relaunch
```

> Downloads may be quarantined by macOS — first run requires
> `xattr -dr com.apple.quarantine "path/to/Wispr Pro.app"` or a right-click → Open.
